# test 后端

仅用于验证框架功能的演示后端，不提供真实认证。

## 测试账号

| 账号 | 密码 | 结果 |
|------|------|------|
| `demo` | `demo123` | 认证成功 |
| `admin` | `admin` | 认证成功 |
| `test` | `test` | 认证成功 |
| 任意 | 错密码 | 密码错误 |
| 不存在的账号 | 任意 | 账号不存在 |
| 含非 ASCII 字符 | 任意 | 非法字符 |

## 开启

在 `config.toml` 中：

```toml
[auths]
test = true
```
